# 系统设置页面 — 实施计划

> **创建时间**：2026-07-19
> **状态**：✅ 已完成

---

## 一、背景

侧边栏已有"系统设置"入口指向 `/settings`，但页面尚未创建（点击 404）。当前部分配置（模型、DB 连接、配额）分散在不同弹窗中管理，联网搜索 Key 只能通过 `.env.local` 全局配置，用户无法自主设置。

## 二、设计原则

- **每个用户一套**：设置按 `user_id` 隔离
- **默认值回退**：用户未设置时，回退到 `.env.local` 全局默认
- **安全边界**：JWT 密钥、数据库连接串等基础设施配置不暴露给用户

## 三、页面内容

系统设置页 = 4 块配置卡片：

| # | 模块 | 类型 | 说明 |
|---|------|------|------|
| 1 | 🤖 AI 模型 | 概览 + 跳转 | 显示当前默认模型名称、已配置数量，点击跳转 ModelConfigPanel |
| 2 | 🔗 数据库连接 | 概览 + 跳转 | 显示已保存连接数量，点击跳转 DbConnectionPanel |
| 3 | 🌐 联网搜索 | **新增可编辑** | 用户填入自己的 Bing API Key，留空则使用系统全局 Key |
| 4 | 📊 默认配额 | **新增可编辑** | 用户级默认值，新建工作空间时作为初始配额（可后续按工作空间单独调整） |

## 四、存储方案

新增 `user_settings` 表（key-value 模式，易扩展）：

```sql
CREATE TABLE user_settings (
    user_id     INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    key         VARCHAR(100) NOT NULL,
    value       TEXT NOT NULL,
    update_time TIMESTAMPTZ DEFAULT NOW(),
    PRIMARY KEY (user_id, key)
);
```

当前支持的 key：
- `bing_search_api_key` — 联网搜索 API Key
- `daily_token_limit` — 新建工作空间默认配额

## 五、API 设计

### `GET /api/user-settings`
返回当前用户的所有设置（含解析后的有效值）。

### `PATCH /api/user-settings`
Body: `{ key: string, value: string | null }`
- `value` 为 `null` 时删除该设置（恢复默认）


干脆利落，我们直接开干！

在终端里直接复制运行下面这条命令。它会启动一个最新的 PostgreSQL 16 版本、且已经内置好 `pgvector` 插件的容器：

Bash

```
docker run -d \
  --name app-agent-db \
  -p 5432:5432 \
  -e POSTGRES_DB=agent_db \
  -e POSTGRES_USER=agent_admin \
  -e POSTGRES_PASSWORD=agent_pass_123 \
  -v pgvector_data:/var/lib/postgresql/data \
  --restart unless-stopped \
  pgvector/pgvector:pg16
```

### 验证是否成功？

容器跑起来后，我们需要进去把向量开关（Extension）打开。

**1. 直接在终端轰入这条命令，进入容器并激活插件：**

Bash

```
docker exec -it app-agent-db psql -U agent_admin -d agent_db -c "CREATE EXTENSION IF NOT EXISTS vector;"
```

**2. 如果看到控制台返回：**

Plaintext

```
CREATE EXTENSION
```

那就说明你的物理底盘和 AI 向量引擎已经彻底合二为一，合体成功！

### 💡 顺手给你备一份 `docker-compose.yml`

如果你平时习惯用 compose 管理，在项目根目录下建个文件把这段丢进去，以后直接 `docker compose up -d` 更舒服：

YAML

```
version: '3.8'

services:
  agent-db:
    image: pgvector/pgvector:pg16
    container_name: app-agent-db
    ports:
      - "5432:5432"
    environment:
      POSTGRES_DB: agent_db
      POSTGRES_USER: agent_admin
      POSTGRES_PASSWORD: agent_pass_123
    volumes:
      - pgvector_data:/var/lib/postgresql/data
    restart: unless-stopped

volumes:
  pgvector_data:
```

现在你可以用 DBeaver、Navicat 或者 IDEA 自带的 Database 工具，连上 `localhost:5432`（用户名：`agent_admin`，密码：`agent_pass_123`），准备写你的第一张智能体文件表了！

如果在 Windows 环境下，直接在普通的 CMD 里运行带换行符 `\` 的 Linux 命令会报错。

为了让你在 Windows 上最稳妥、最舒服地跑起来，我为你提供 **CMD（命令提示符）** 和 **PowerShell** 两个版本的启动命令。选一个你常用的终端复制即可。

### 💻 选项一：Windows PowerShell 版本（推荐，直接复制）

在 Windows 上按 `Win + X` 键，选择 **Windows PowerShell** 或 **终端 (Terminal)**，复制并右键粘贴以下命令：

PowerShell

```
docker run -d `
  --name app-agent-db `
  -p 5432:5432 `
  -e POSTGRES_DB=agent_db `
  -e POSTGRES_USER=agent_admin `
  -e POSTGRES_PASSWORD=agent_pass_123 `
  -v pgvector_data:/var/lib/postgresql/data `
  --restart unless-stopped `
  pgvector/pgvector:pg16
```

*(注意：PowerShell 的换行符是反单引号 ```)*

### 💻 选项二：Windows CMD 版本（传统命令提示符）

如果你习惯用最老派的 **CMD 窗口**，复制这行去掉所有换行、拼成一条直线的命令：

DOS

```
docker run -d --name app-agent-db -p 5432:5432 -e POSTGRES_DB=agent_db -e POSTGRES_USER=agent_admin -e POSTGRES_PASSWORD=agent_pass_123 -v pgvector_data:/var/lib/postgresql/data --restart unless-stopped pgvector/pgvector:pg16
```

### ⚡ 核心一步：激活向量插件

等上面任何一个 Docker 容器成功跑起来之后，**必须在 Windows 终端里执行下面这行命令**，把向量扩展在 `agent_db` 数据库里激活：

DOS

```
docker exec -it app-agent-db psql -U agent_admin -d agent_db -c "CREATE EXTENSION IF NOT EXISTS vector;"
```

**检查结果：**

如果屏幕上干净利落地返回了 `CREATE EXTENSION`，说明你的 Windows 环境已经成功白嫖了一套工业级的向量数据库。现在打开你的连接工具，连上 `localhost:5432` 就可以开搞了！

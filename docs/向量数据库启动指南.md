# 向量数据库启动指南

> **用途**：单独启动 Aura 项目的 PostgreSQL + pgvector 数据库容器，不启动应用。
> **时间**：约 2 分钟。

---

## 前置条件

- **Docker Desktop** 已安装并运行（[下载](https://www.docker.com/products/docker-desktop/)）
- 确保 **5432 端口** 未被占用

验证 Docker 是否就绪：

```bash
docker info
```

---

## 启动方式

### 方式一：一键脚本（Windows 推荐）

直接双击运行项目根目录下的批处理脚本：

```
deploy\pgvector-start.bat
```

脚本会自动检查 Docker 状态、拉取镜像、启动容器，并在成功后打印连接信息。

### 方式二：docker-compose（跨平台）

```bash
cd deploy
docker compose up -d postgres
```

> 容器名称为 `aura-postgres`，数据持久化在 Docker Volume `pgdata` 中。

### 方式三：docker run（无 compose）

**PowerShell：**

```powershell
docker run -d `
  --name aura-postgres `
  -p 5432:5432 `
  -e POSTGRES_USER=root `
  -e POSTGRES_PASSWORD=root `
  -e POSTGRES_DB=aura_db `
  -v pgdata:/var/lib/postgresql/data `
  --restart unless-stopped `
  pgvector/pgvector:pg16
```

**CMD（单行）：**

```cmd
docker run -d --name aura-postgres -p 5432:5432 -e POSTGRES_USER=root -e POSTGRES_PASSWORD=root -e POSTGRES_DB=aura_db -v pgdata:/var/lib/postgresql/data --restart unless-stopped pgvector/pgvector:pg16
```

---

## 激活 pgvector 扩展

容器启动后，必须执行一次以启用向量功能：

```bash
docker exec -it aura-postgres psql -U root -d aura_db -c "CREATE EXTENSION IF NOT EXISTS vector;"
```

看到以下输出即表示激活成功：

```
CREATE EXTENSION
```

## 验证连接

用任意数据库客户端连接：

| 参数     | 值                                          |
|----------|---------------------------------------------|
| 主机     | `localhost`                                 |
| 端口     | `5432`                                      |
| 用户     | `root`                                      |
| 密码     | `root`                                      |
| 数据库   | `aura_db`                                   |
| 连接串   | `postgresql://root:root@localhost:5432/aura_db` |

---

## 常用操作

```bash
# 查看容器状态
docker ps --filter name=aura-postgres

# 进入数据库命令行
docker exec -it aura-postgres psql -U root -d aura_db

# 停止数据库
docker stop aura-postgres

# 重新启动（数据不丢失）
docker start aura-postgres

# 完全删除（含数据卷）
docker stop aura-postgres
docker rm aura-postgres
docker volume rm deploy_pgdata
```

## 故障排查

| 现象                   | 解决                                                         |
|------------------------|--------------------------------------------------------------|
| `ECONNREFUSED`         | Docker 未启动，或容器已停止。运行 `docker start aura-postgres` |
| 端口 5432 被占用       | 停止占用端口的进程，或修改 `docker-compose.yml` 中左侧端口号   |
| 镜像拉取失败           | 检查网络，或配置 Docker 镜像加速器                             |
| `vector` 扩展不可用    | 镜像必须是 `pgvector/pgvector:pg16`，非普通 `postgres` 镜像   |

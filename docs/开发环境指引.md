# Aura 开发环境指引

## 架构总览

Aura 是一个 **Next.js 16 全栈应用**，开发环境只需要启动两个东西：

```
┌──────────────────────────────────┐
│  PostgreSQL + pgvector (Docker)  │  ← 数据库，端口 5432
│  容器名: aura-postgres           │
└──────────────────────────────────┘
              ▲
              │
┌──────────────────────────────────┐
│  Next.js 16 (dev server)         │  ← 全栈应用，端口 8086
│  前端 React + 后端 API           │
└──────────────────────────────────┘
```

没有独立的 Node 后端服务 —— Next.js 的 API Route 就是后端。

## 首次启动（从头搭建）

### 1. 环境变量

```bash
cd web-aura-next
cp .env.example .env.local
```

编辑 `.env.local`，填入实际值。**至少需要这 3 个**：

```env
AURA_MODE=server
DEEPSEEK_API_KEY=sk-你的key
AURA_JWT_SECRET=随机字符串（越长越好）
```

其他有默认值的可以不动。完整变量说明见 `.env.example` 注释。

### 2. 启动数据库

双击 `deploy\docker-pgvector-start.bat`，或在终端执行：

```bash
cd deploy
docker compose up -d postgres
```

这会拉取 `pgvector/pgvector:pg16` 镜像并启动容器。

数据库连接信息：
```
地址:   localhost:5432
用户:   root
密码:   root
数据库: aura_db
连接串: postgresql://root:root@localhost:5432/aura_db
```

验证数据库是否就绪：

```bash
docker exec aura-postgres pg_isready -U root -d aura_db
```

### 3. 启动开发服务器

双击 `deploy\dev-start.bat`，这个脚本会自动执行：

1. `npm install` — 安装依赖
2. `npx tsx src/lib/db/migrate.ts` — 执行数据库迁移（建表）
3. `npm run dev` — 启动 Next.js 开发服务器
4. 自动打开浏览器到 `http://localhost:8086`

也可以分步手动执行：

```bash
cd web-aura-next
npm install
npm run db:migrate
npm run dev
```

## 日常开发（数据库已启动）

数据库容器启动后就一直在后台运行（Docker Desktop 不关就一直跑），日常只需要：

```bash
cd web-aura-next
npm run dev
```

浏览器访问 `http://localhost:8086`。

> 注意：数据库容器关闭后需要按顺序重启（先数据库，再 Next.js），因为 `dev-start.bat` 里的迁移步骤会尝试连接数据库。

## npm 脚本速查

全部在 `web-aura-next/package.json` 中：

| 命令 | 作用 |
|------|------|
| `npm run dev` | 启动开发服务器（端口 8086） |
| `npm run build` | 生产构建（Standalone 模式输出到 `.next/standalone/`） |
| `npm start` | 启动生产服务器 |
| `npm run lint` | 运行 ESLint |
| `npm run db:generate` | 根据 schema 变更生成迁移文件 |
| `npm run db:migrate` | 执行未应用的迁移到数据库 |
| `npm run db:push` | 直接把 schema 推到数据库（跳过迁移文件，开发期用） |
| `npm run tauri dev` | 启动 Tauri 桌面客户端开发模式 |
| `npm run tauri build` | 构建 Tauri 桌面客户端 `.exe` |

## 数据库相关

### 迁移流程

当修改了 `src/lib/db/schema/index.ts` 后：

```bash
npm run db:generate    # 生成 SQL 迁移文件到 drizzle/
npm run db:migrate     # 应用到数据库
```

### 进入数据库

```bash
docker exec -it aura-postgres psql -U root -d aura_db
```

### 启用 pgvector 扩展

```bash
docker exec -it aura-postgres psql -U root -d aura_db -c "CREATE EXTENSION IF NOT EXISTS vector;"
```

### 常用 Docker 命令

```bash
docker stop aura-postgres        # 停止数据库
docker start aura-postgres       # 启动已有容器
docker rm aura-postgres          # 删除容器（数据在 volume 中不会丢）
docker compose down -v           # 删除容器和 volume（数据彻底清空）
```

## 端口一览

| 端口 | 服务 | 配置位置 |
|------|------|----------|
| 5432 | PostgreSQL | `deploy/docker-compose.yml` |
| 8086 | Next.js 开发服务器 | `package.json` → `"dev": "next dev -p 8086"` |
| 8086 | Next.js 生产服务器 | `bin/aura-server/.env` → `PORT=8086` |
| 8086 | Tauri 开发模式 | `src-tauri/tauri.conf.json` → `devUrl` |

所有应用层服务都收敛在 **8086**。

## 双模式架构

Aura 支持两种运行模式，通过 `AURA_MODE` 环境变量切换：

| 模式 | `server`（默认） | `client` |
|------|-------------------|----------|
| LLM 调用 | 直连 DeepSeek API | 转发到远程 Server |
| 文件系统 | 服务端本地 `DATA_ROOT` | Tauri 原生 FS |
| 数据库 | 直连 PostgreSQL | 不直连 |
| 典型用途 | 内网部署服务器 | 桌面客户端 `.exe` |

详见 `docs/双端模式.md`。

## 生产构建与内网部署

一个命令构建：

```bash
deploy\build-server-lan.bat
```

构建流程（7 步）：
1. 环境检查（Node.js）
2. `npm install` + `npm run build`
3. 提取 `.next/standalone/` 产物
4. 复制 `public/` 和 `.next/static/`
5. 生成 `.env` 运行配置
6. 生成 WinSW 服务定义（`AuraServer.xml`）
7. 打包 WinSW + 生成 `startServer.bat` / `stopServer.bat`

产物在 `bin/aura-server/`，完整目录结构：

```
bin/aura-server/
├── server.js              ← Next.js Standalone 入口
├── node_modules/          ← 生产依赖
├── .next/                 ← 编译产物
├── public/                ← 静态资源
├── .env                   ← 运行环境变量
├── AuraServer.exe         ← WinSW 可执行
├── AuraServer.xml         ← Windows 服务定义
├── startServer.bat        ← 安装并启动 Windows 服务（需管理员）
└── stopServer.bat         ← 停止并卸载 Windows 服务（需管理员）
```

部署到目标机器：

```bash
# 1. 把 bin/aura-server/ 全部复制到 D:\app\aura-server\
# 2. 确保目标机器有 PostgreSQL 和 Node.js
# 3. 以管理员身份运行
D:\app\aura-server\startServer.bat

# 或者手动运行（不用 Windows 服务）
cd D:\app\aura-server
node server.js
```

## 常见问题

**Q: 启动 dev 时报数据库连接失败？**
先确认 Docker Desktop 已运行，再用 `docker ps` 检查 `aura-postgres` 容器是否存在。

**Q: 端口 8086 被占用？**
```bash
netstat -ano | findstr :8086
```
找到 PID 后在任务管理器结束，或改 `package.json` 中的端口号。

**Q: 数据库迁移失败？**
先确保 pgvector 扩展已启用，再手动执行迁移：
```bash
docker exec -it aura-postgres psql -U root -d aura_db -c "CREATE EXTENSION IF NOT EXISTS vector;"
npm run db:migrate
```

**Q: Tauri 开发模式报错？**
需要安装 Rust 工具链：
```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

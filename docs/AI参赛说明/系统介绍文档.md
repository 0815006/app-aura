> 版本：v0.1.0
> 类型：全栈 AI 智能体平台

---

## 一、系统概述

Aura 是一个面向研发与运维全流程的通用 AI 智能体工作台。它基于 Next.js + Vercel AI SDK + DeepSeek 构建，采用"双端异构"架构——服务端承载 AI 编排与数据持久化，桌面客户端（Tauri）提供原生操作系统能力，两者共用同一套代码。

### 1.1 核心能力

- **AI 原生工作台**：流式对话 + 多步工具调用，Agent 可自主读取文件、分析数据、生成报告
- **8 大原子工具**：文件感知、资产产出、沙箱计算、外部连接四类工具，覆盖 90% 的日常工作场景
- **7 大场景专家**：数据库诊断、系统性能分析、需求分析、功能点估算、测试分析、UI 原型校验、COBOL→Java 重构——一键切换
- **双端协同**：服务端重活（AI 推理、数据库操作）、客户端轻壳（文件浏览、Shell 执行），各司其职
- **权限与安全**：JWT 认证、路径越权防护、API Key 加密、用户数据隔离
- **工作空间持久化**：聊天历史落库、长期记忆向量检索、文件产出物自动归档

### 1.2 适用场景

| 场景 | 目标用户 | 典型输入 | 典型产出 |
|------|---------|---------|---------|
| 数据库慢 SQL 诊断 | DBA / 后端开发 | 数据库连接凭证 | 慢 SQL 诊断报告 + 优化索引脚本 |
| 系统性能分析 | 运维 / SRE | 系统监控 CSV、nmon 报告 | 瓶颈根因分析报告 |
| 需求分析与架构拆解 | 架构师 / PM | PRD 文档、API 规范 | 结构化需求清单 + 架构差异评估 |
| 功能点估算（NESMA/IFPUG） | 技术评审 / PMO | 需求文档、接口规范 | 审计级功能点估算报告 + 人月评估 |
| 测试分析（银行合规） | 测试工程师 / QA | 需求文档 + 功能点明细表 | Excel 用例集 + 造数规则 JSON |
| UI 原型契约与自动化校验 | QA / 前端开发 | 原型契约 JSON、目标 URL | DOM 语义对比审计报告 |
| COBOL → Java 架构重构 | 核心系统架构师 | COBOL Copybook 源码 | 等价性审计报告 + Java 代码（规划中） |

## 二、技术架构

### 2.1 技术选型

| 层次 | 技术 | 说明 |
|------|------|------|
| 全栈框架 | Next.js 15 (Standalone) | 单一工程 + 独立部署 |
| AI 编排 | Vercel AI SDK (`ai` + `@ai-sdk/deepseek`) | 流式对话 + 工具调用状态机 |
| 大模型 | DeepSeek-R1 / V3 | 高性价比强推理能力 |
| 数据库 | PostgreSQL 16 + pgvector | 结构化数据 + 向量检索 |
| ORM | Drizzle ORM | 类型安全 + 自动迁移 |
| 前端 UI | React 19 + Tailwind CSS 4 | 组件化 + 原子化样式 |
| 桌面壳 | Tauri v2 (Rust) | Windows .exe + 系统级 API |
| 浏览器自动化 | Playwright | UI 校验场景无头浏览器 |
| 文件生成 | ExcelJS | 结构化 Excel 输出 |
| 认证 | jose (JWT) + bcryptjs | 密码哈希 + Token 签发 |

## 三、功能模块

### 3.1 智能体对话工作台

主界面采用「左侧文件空间 + 右侧 AI 控制台」布局：

- 流式逐字输出（打字机效果）
- 工具调用实时展示（步骤面板 + 折叠详情）
- @文件语法（输入区直接引用工作空间文件）
- 场景选择器（一键切换专家角色）
- 模型切换器（多模型配置动态切换）

### 3.2 能力展示页 (`/capabilities`)

按四层 16 项能力分类展示：

- **L1 SDK 底层能力**：多模型统一抽象、流式传输、结构化输出、工具调用闭环、原生遥测
- **L2 通用基础能力**：跨文件读写、自主规划、步骤展示、用量审计、场景驱动
- **L3 高阶增强能力**：渐进式预览、人机协同、多模态调试
- **L4 外部配套能力**：物理安全沙箱、状态持久化、长期记忆、动态配额熔断

### 3.3 工作空间管理

- 创建/删除工作空间（服务端文件系统）
- 工作空间树形目录浏览（`/api/workspaces/tree`）
- 文件上传/预览/下载
- 长期记忆自动提取与注入

### 3.4 系统设置 (`/settings`)

- 模型配置管理（多组 API Key 加密存储）
- 用户偏好设置
- 数据库连接管理（DBA 场景）

### 3.5 知识库 (`/knowledge`)

- 向量化文档存储（pgvector）
- 语义搜索检索

## 五、安全设计

- **JWT 认证**：HS256 算法，7 天过期，HttpOnly Cookie
- **双端权限模型**：服务端 JWT 鉴权，客户端免登录 + Header Key
- **API Key 加密**：AES-256-GCM 加密存储，API 返回不泄露
- **路径越权防护**：双重校验（DB 归属 + 路径边界）
- **用户数据隔离**：`DATA_ROOT/workspaces/user_{id}/` 目录级隔离
- **数据库只读**：DB 工具仅允许 SELECT，写操作强制拦截
- **密钥隔离**：DeepSeek API Key 仅存服务端，客户端不持有

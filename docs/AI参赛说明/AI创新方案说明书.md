# Aura 智能体平台 — AI 创新方案说明书

> 版本：v1.0
> 参赛项目：Aura 多场景通用智能体工作台
> 核心技术栈：Next.js 15 + Vercel AI SDK + DeepSeek + Tauri v2

---

## 一、项目简介

### 1.1 一句话概括

**Aura 是一个「双端协同、场景可插拔」的通用 AI 智能体工作台**——服务端担纲 AI 大脑，桌面客户端提供原生操作系统接入能力，通过 8 大原子工具 + 7 大场景专家的架构，将 DeepSeek 等大模型的推理能力转化为面向研发、运维、测试全流程的可执行生产力。

### 1.2 解决的问题

传统 AI 对话产品面临三个核心痛点：

| 痛点 | 传统方案 | Aura 方案 |
|------|---------|----------|
| **AI 与文件系统隔离** | 用户手动复制粘贴文件内容到对话框 | Agent 主动调用工具读取工作空间文件，无需用户搬运 |
| **AI "只会说不会做"** | 只能给建议，用户自己执行 | Agent 通过工具直接生成文件、执行脚本、写入报告，物理产出交付物 |
| **场景专用 vs 通用能力冲突** | 为每个场景（DBA诊断、性能分析、测试报告）单独开发独立系统 | 一套底座 + System Prompt 切换 = 无限场景扩展，零代码新增 |

### 1.3 创新亮点

1. **双端异构架构**：服务端（AI 编排 + 数据库 + 文件存储）与客户端（Tauri 桌面壳 + 本地文件/Shell 原生能力）共用一套 Next.js 代码，通过 `AURA_MODE` 环境变量编译分叉，最大程度复用
2. **8 大原子工具底座**：文件感知、资产产出、沙箱计算、外部连接四类原子工具构成 Agent 的「眼和手」，大模型只负责推理决策，工具层负责执行
3. **场景驱动型智能体**：通过 System Prompt 动态注入 + 工具组合切换，同一个 Agent 引擎可变身 DBA 诊断专家、性能分析专家、需求架构师、测试报告写手——新增场景只需配置一段 Prompt，无需编码
4. **流式透明执行**：Agent 的每一步思考、每一次工具调用、每一个中间结果都通过 SSE 流式推送前端控制台，用户可以看到 AI "在做什么"，而不仅是最终答案

## 三、AI 辅助方案前后效能对比

### 3.1 现有流程 vs Aura 流程

| 维度 | AI 前（纯人工） | AI 前（通用对话机器人） | Aura 智能体 |
|------|:---:|:---:|:---:|
| **数据库慢 SQL 诊断** | DBA 手动执行 EXPLAIN，翻阅文档，耗时 30-60 分钟 | 粘贴 SQL 到 ChatGPT，获得文字建议，仍需手动验证 | Agent 自动连库 → EXPLAIN 分析 → 生成优化脚本，耗时 3-5 分钟 |
| **性能测试报告撰写** | 测试人员从 JMeter CSV 手动计算 P99/TPM，填入 Word 模板，耗时 2-4 小时 | 粘贴数据到 AI，获得 Markdown 格式分析，手动搬运到 Word | Agent 自动扫描工作空间 CSV → 调用 Excel 生成 —→ 输出格式化报告，耗时 2-5 分钟 |
| **需求文档拆解** | 架构师阅读 50 页 PRD，手动拆解功能点，耗时 2-3 天 | 分段粘贴到 AI，逐步交互，缺少结构化输出和持久化 | Agent 读取文档 → RAG 向量检索关联 → 结构化 JSON 输出 → 写入工作空间，耗时 5-10 分钟 |
| **UI 合规校验** | QA 逐页对比原型图与实际页面，手工记录差异，耗时 4-8 小时 | 无法完成（AI 不能操作浏览器） | Agent 驱动 Playwright 无头浏览器 → 抓取 DOM → 比对原型契约 → 输出审计报告，耗时 2-4 分钟 |
| **跨场景切换** | 切换工具链，重新登录，打开不同 IDE/客户端 | 手动切换对话，丢失上下文 | 点击切换场景 → System Prompt 自动加载 → 工具集自动适配，切换 < 1 秒 |

| 指标 | 纯人工 | 通用聊天 AI | Aura 智能体 | 提升倍数 |
|------|:---:|:---:|:---:|:---:|

| 报告产出速度 | 1-2 天 | 30 分钟 (仍需手动整理) | 2-5 分钟 (自动落盘) | **~30x** |
| 上下文保持 | 依赖人工记忆 | 单次对话丢失 | 工作空间持久化 + 长期记忆 | 质的飞跃 |
| 产出物标准化 | 依赖个人习惯 | AI 输出格式不稳定 | 工具层保证结构化输出 | 从 60% → 95% |
| 新人上手成本 | 需培训 1-2 周 | 需培训 Prompt 技巧 | 选择场景即用 | 从 2 周 → 0 |
| 多场景支持 | 每人专精 1-2 个领域 | 需多轮 Prompt 调整 | 一键切换，即时生效 | ∞ |

## 四、技术栈一览

| 层级 | 技术选型 | 用途 |
|------|---------|------|
| 全栈框架 | Next.js 15 (Standalone) | 前后端一体，API Route + SSR |
| AI 引擎 | Vercel AI SDK (`streamText`) | 流式对话 + 工具调用状态机 |
| 大模型 | DeepSeek-R1 / V3 | 高性价比强推理能力 |
| 数据库 | PostgreSQL 16 + pgvector | 聊天历史 + 向量检索 (RAG) |
| ORM | Drizzle ORM | 数据库迁移与类型安全查询 |
| 桌面壳 | Tauri v2 (Rust) | Windows .exe 打包 + 原生 API |
| 前端 UI | React 19 + Tailwind CSS 4 | 组件化界面 |
| 运行时校验 | Zod | 工具参数 + API 请求校验 |
| 文件生成 | ExcelJS | 结构化 Excel 输出 |
| 浏览器自动化 | Playwright | UI 原型合规校验场景 |

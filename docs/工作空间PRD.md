# 工作空间（Workspace）需求 PRD

> 版本：v1.2 | 状态：待审核

---

## 1. 部署与数据路径

| 项目 | 路径 |
|------|------|
| 服务部署目录 | `D:\app\aura-server` |
| 数据根目录 | `D:\data\aura\` |

`D:\data\aura\` 下按业务内容划分子目录：

```text
D:\data\aura\
├── workspaces\             # 服务器端工作空间根目录（按 UUID 分子目录）
├── uploads\                # 通用上传（后续扩展）
└── ...                     # 其他业务数据目录
```

## 2. 工作空间双模式

| 模式 | 数据位置 | 持久化 |
|------|---------|--------|
| **客户端版** | 用户本机指定目录 | 文件在本地，**后端不记录**（无需 DB 行） |
| **服务器端版** | `D:\data\aura\workspaces\{uuid}\` | 文件在服务器 + `workspaces` 表一行元数据 |

### 2.1 客户端版

- Agent 直接读写用户本机选定的目录。
- 目录结构由用户自由组织，支持嵌套子目录和任意文件。
- **不做服务端持久化**：不存 DB 记录，不存文件副本。用户下次打开时重新选择本地目录即可。
- 数据始终在用户自己机器上，Aura 仅作为本地工具读写。

### 2.2 服务器端版

- Agent 操作 `D:\data\aura\workspaces\{uuid}\` 下的文件。
- 每个工作空间按 UUID 物理隔离。
- **不分输入/输出区**，由用户和 Agent 自由创建子目录和文件。
- 目录结构：

```text
D:\data\aura\workspaces\{uuid}\
├── .meta\                  # 系统隐藏目录（Agent 配置快照）
└── {用户/Agent 自由创建的子目录和文件}...
```

### 2.3 统一规则

- 支持任意子目录和文件，嵌套不受限。
- 所有文件操作工具必须校验路径不逃逸当前工作空间根目录（路径越权校验）。

## 3. 页面布局：三栏结构

主工作区采用 **三栏布局**，取代现有两栏 Sidebar + Main 结构：

```
┌──────────────┬────────────────────┬────────────────────┐
│ 工作空间树   │   中间：预览区      │   右侧：AI 聊天区   │
│ (可折叠)     │   (默认等宽)       │   (默认等宽)        │
│              │                    │                    │
│ ├─ 📁 子目录A│  打开文件的        │  与 Agent 对话     │
│ │  ├─ 📄 a   │  内容预览/编辑     │  流式输出          │
│ │  └─ 📄 b   │                    │                    │
│ ├─ 📁 子目录B│                    │                    │
│ └─ 📄 readme │                    │                    │
│              │                    │                    │
│[退出][载入]  │                    │                    │
│[新建]        │                    │                    │
└──────────────┴────────────────────┴────────────────────┘
       ↑               ↑                     ↑
   可折叠/展开   可拖拽分隔线A        可拖拽分隔线B
              （左右调整左侧占比）  （左右调整中间与右侧占比）
```

### 3.1 三栏规格

| 区域 | 默认宽度 | 行为 |
|------|---------|------|
| **左侧：工作空间树** | 240px（展开）/ 0（折叠） | 可折叠；展开时宽度可通过分隔线 A 拖拽调整 |
| **中间：预览区** | 与右侧等宽（各占剩余空间 50%） | 展示选中文件的内容预览/编辑；宽度可通过分隔线 A、B 调整 |
| **右侧：AI 聊天区** | 与中间等宽（各占剩余空间 50%） | Agent 对话交互，流式输出；宽度可通过分隔线 B 调整 |

### 3.2 两条可拖拽分隔线

| 分隔线 | 位置 | 作用 |
|--------|------|------|
| **分隔线 A** | 左侧工作空间树 ↔ 中间预览区之间 | 左右拖拽调整左侧栏宽度 |
| **分隔线 B** | 中间预览区 ↔ 右侧 AI 聊天区之间 | 左右拖拽调整中间与右侧宽度比例 |

- 两条分隔线均支持 **实时拖拽**，拖拽范围受各区域最小宽度限制（≥ 200px）。
- 左侧折叠时，分隔线 A 随左侧栏隐藏；分隔线 B 仍可正常拖拽。
- 左侧展开时，分隔线 A 与 B 均可用，三栏宽度独立调整。

### 3.3 左侧工作空间树操作

- **目录支持折叠/展开**：所有子目录节点均可点击折叠或展开，与文件选择器行为一致。递归嵌套的深层子目录同样支持。
- **面板折叠/展开**：点击折叠按钮收起整个左侧栏，再次点击展开至 240px（或上次拖拽后的宽度）。
- **点击文件**：在中间预览区打开文件内容。
- **右键菜单**：新建文件/文件夹、重命名、删除（服务器端模式）。

### 3.4 底部三个核心按钮

| 按钮 | 行为 |
|------|------|
| **退出工作空间** | 清空当前工作空间上下文，回到无空间状态。客户端版仅清内存，服务器端版下次可重新载入。 |
| **载入服务器端工作空间** | 弹出列表，选择已有的服务器端工作空间并激活。加载其文件树 + 历史对话 + 上下文快照。 |
| **新建服务器端工作空间** | 输入名称 → 调用 API 创建 → `D:\data\aura\workspaces\{uuid}\` 目录生成 + DB 记录写入 → 自动激活。 |

---

## 4. 服务器端工作空间生命周期

| 操作 | 说明 |
|------|------|
| **新建** | 指定名称 → API 创建目录 + 写入 `workspaces` 行 → 前端激活 |
| **载入（续用）** | 选择已有空间 → 加载历史对话 + 扫描文件清单注入 System Prompt + 重建上下文快照 |
| **退出** | 清空当前会话上下文，回到无空间状态 |
| **删除** | 物理删除 `D:\data\aura\workspaces\{uuid}\` 目录 + 删除 DB 记录 |

---

## 5. 服务器端数据持久化

### 5.1 `workspaces` 表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| name | VARCHAR | 空间名称 |
| context_snapshot | JSONB | 续用上下文（DB 连接串、Prometheus 地址等） |
| status | ENUM | `active` / `archived` |
| create_time | TIMESTAMP | 创建时间 |
| update_time | TIMESTAMP | 最后活跃时间 |

> **注意**：客户端版不写入此表。`mode` 和 `local_path` 字段已移除——客户端版完全无服务端痕迹。

### 5.2 文件存储

- **服务器端版**：`D:\data\aura\workspaces\{uuid}\`，工具层所有读写操作必须传入 `workspaceId` 解析路径。
- **客户端版**：文件始终在用户本机，Aura 直接操作本地路径。

---

## 6. 前端交互要点

- **三栏布局**：左侧工作空间树（可折叠） + 中间预览区 + 右侧 AI 聊天区，中间与右侧默认等宽。
- **两条可拖拽分隔线**：左侧↔中间（分隔线 A）、中间↔右侧（分隔线 B）均支持左右拖拽调整宽度，各区域最小 200px。
- `useChat` 请求体固定携带当前 `workspaceId`（客户端模式可为 `null`）。
- 点击左侧树文件 → 中间预览区打开内容；右侧 AI 聊天区独立运作不受影响。
- 文件变更后（新建/修改/删除），树形目录实时刷新并高亮新节点。
- 客户端模式下，用户通过系统文件选择器指定本地根目录后，前端直接读取本地目录树渲染。

---

> **核心原则**：客户端版零服务端痕迹，服务器端版一行 DB + 一个目录。简单、隔离、可续用。
